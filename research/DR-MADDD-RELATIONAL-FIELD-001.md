## 4. Compass / Knife duality — research compression

No new operator follows from this metaphor.

```text
COMPASS
  asks: which route through the constituted field is relevant to this situated asking?

KNIFE
  asks: what minimal declared boundary change makes a previously unavailable route reachable?
```

Dogram translations:

```text
Compass-like discrimination -> delta / rectangle
Knife-like seam intervention -> reach / ablate
```

The important refusal is:

```text
FOUND PATH != CREATED PATH
```

A query that selects an existing route and a mutation that creates new reachability are different histories and require different receipts.

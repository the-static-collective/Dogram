# MAZURKIEWICZ-TRACE-QUOTIENT-001

Status: bounded research slice; no public operator promotion.

## Question

Can two systems expose exactly the same declared linear executions and event-count surface while differing only in which adjacent actions are licensed to commute, thereby producing different trace quotients?

Yes.

## Frozen specimen

Alphabet:

```text
Sigma = {a,b}
```

Declared linear language in both controls:

```text
L = {ab, ba}
```

Both words have the same Parikh vector:

```text
a:1, b:1
```

Parallel control independence relation:

```text
I_parallel = {(a,b),(b,a)}
```

Ordered control:

```text
I_ordered = empty
```

Mazurkiewicz trace equivalence is the least congruence generated by swapping adjacent independent letters.

Therefore:

```text
parallel: [ab] = {ab,ba} = [ba]     -> 1 trace class
ordered:  [ab] = {ab}, [ba] = {ba}  -> 2 trace classes
```

Exact quotient delta:

```text
linear-language delta = 0
Parikh-surface delta = 0
trace-class-count delta = 1
```

## Seals

**SAME LINEAR LANGUAGE != SAME TRACE QUOTIENT.**

**AN INTERLEAVING RECORD CAN PRESERVE EVERY ORDERED EXECUTION WHILE ERASING WHICH ORDERS WERE OPTIONAL.**

**THE INDEPENDENCE RELATION IS PART OF THE DECODER RECEIPT.**

## Documented mathematics

Trace theory models concurrency using a symmetric irreflexive independence relation on an alphabet. The trace monoid is the quotient of the free word monoid by the congruence generated by commuting adjacent independent actions. See Diekert & Muscholl, *Trace Theory*, Encyclopedia of Parallel Computing, DOI `10.1007/978-0-387-09766-4_491`, and Husainov, *Cubical Sets and Trace Monoid Actions*, The Scientific World Journal (2013), DOI `10.1155/2013/285071`.

The distinction is also consistent with true-concurrency literature: partial-order/event-structure semantics preserves concurrency information that a purely interleaved view can lose. See León, Haar & Longuet, *Model-based testing for concurrent systems with labelled event structures*, Software Testing, Verification and Reliability 24(7) (2014), DOI `10.1002/stvr.1543`, and Chen et al., *Confusion Analysis and Detection for Workflow Nets*, Discrete Dynamics in Nature and Society (2014), DOI `10.1155/2014/825313`.

Janicki, Kleijn, Koutny & Mikulski further distinguish classical Mazurkiewicz traces from step traces, where simultaneous steps are observable rather than represented only by commuting sequential observations: *Step traces*, Acta Informatica 53(1) (2016), DOI `10.1007/s00236-015-0244-z`.

## Inference

The finite specimen shows exactly one thing: holding the word language and event multiplicities fixed does not determine the trace quotient if the independence relation changes.

It does not show that either quotient is the correct model of any real process. The independence relation is declared mathematical structure and must be justified separately when imported from a source domain.

## Refusals

```text
TRACE EQUIVALENCE != HISTORICAL IDENTITY
INDEPENDENCE RELATION != CAUSAL INDEPENDENCE
COMMUTING ACTIONS != SIMULTANEOUS OCCURRENCE
SAME PARIKH VECTOR != SAME HISTORY
SAME LINEAR LANGUAGE != SAME CONCURRENCY SEMANTICS
TRACE CLASS != EVIDENCE CLASS
PARTIAL ORDER != AUTHORITY
```

## Relation to PETRI-INCIDENCE-CONCURRENCY-001

PR #112 provides a Petri-net carrier where the same sequential reachability surface admits different joint-step concurrency because a balanced shared-resource self-loop disappears from the incidence matrix.

This slice isolates the next mathematical layer without depending on that branch: once a candidate independence relation is declared, the word language can be quotiented into trace classes. The quotient itself therefore requires its own receipt.

No claim is made that the independence relation can be reconstructed from a word language alone.

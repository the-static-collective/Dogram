# SHEAF-HOLONOMY-GLOBAL-SECTION-001

Status: bounded research slice; no public operator promotion.

## Question

Can two cellular sheaves keep the same underlying graph, the same stalk dimensions, and the same absolute size of every local transport map while differing in whether any nonzero global section exists?

Yes. The missing datum is the signed gluing/transport around the cycle.

## Frozen specimen

Use the oriented triangle

`0 -> 1 -> 2 -> 0`.

Every vertex stalk and every edge stalk is one-dimensional. Freeze scalar transports `t01,t12,t20 in {+1,-1}` and impose

- `x1 = t01*x0`,
- `x2 = t12*x1`,
- `x0 = t20*x2`.

The coboundary/constraint matrix is

```text
[-t01   1      0 ]
[ 0    -t12    1 ]
[ 1     0    -t20]
```

A global section is exactly a vector in its kernel.

### Flat control

For `(t01,t12,t20)=(+1,+1,+1)`, the cycle product is `+1`.

```text
D = [-1  1  0]
    [ 0 -1  1]
    [ 1  0 -1]
```

`rank(D)=2`, so the global-section space has dimension `1`, generated by the constant assignment `(1,1,1)`.

The sheaf Laplacian `L=D^T D` is

```text
[ 2 -1 -1]
[-1  2 -1]
[-1 -1  2]
```

with characteristic polynomial `lambda*(lambda-3)^2` and determinant `0`.

### Twisted control

Change only the final transport sign: `(t01,t12,t20)=(+1,+1,-1)`. All stalk dimensions stay one and every local map still has absolute value one.

```text
D = [-1  1  0]
    [ 0 -1  1]
    [ 1  0  1]
```

Now `rank(D)=3`, so the global-section space is zero-dimensional.

```text
L = [ 2 -1  1]
    [-1  2 -1]
    [ 1 -1  2]
```

Its characteristic polynomial is `(lambda-1)^2*(lambda-4)` and its determinant is `4`.

The implementation exhaustively checks all eight sign assignments. In this bounded rank-one triangle model:

```text
transport product +1  <=>  dim H^0 = dim(global sections) = 1  <=> det(L)=0
transport product -1  <=>  dim H^0 = dim(global sections) = 0  <=> det(L)=4
```

This is exact integer/rational arithmetic, not numerical inference.

## Documented mathematics

Hansen & Ghrist, *Toward a Spectral Theory of Cellular Sheaves*, Journal of Applied and Computational Topology 3 (2019), DOI `10.1007/s41468-019-00038-7`, develops cellular sheaf Laplacians and the relation between sheaf cohomology/global sections and the kernel of the degree-zero Laplacian. In particular, global sections are compatible vertex assignments and are precisely the kernel of the coboundary; the degree-zero sheaf Laplacian is `delta^* delta`, hence has the same kernel.

A 2026 review/application treatment by Cox, *Integrating Fragmented Risk Knowledge: Sheaf Theory for Risk Analysts*, Risk Analysis 46(3), DOI `10.1111/risa.70206`, likewise emphasizes restriction maps as the data specifying local compatibility and cohomology as a local-to-global obstruction mechanism. That application domain is not imported into Dogram; only the mathematical local-to-global distinction is relevant here.

Wolfram was asked for the exact signed-sheaf calculation but returned no direct computation. Its documentation independently confirms the standard matrix/eigensystem machinery; therefore this slice makes no Wolfram-verification claim for the sheaf-specific result.

## Inference

For this frozen rank-one cycle, the product of the three signed transports is the complete obstruction to a nonzero global section. This follows directly by composing the three compatibility equations and is exhaustively replayed over all eight sign assignments.

## 6. `DUAL-TRANSPORT-001` — EXECUTABLE HOSTILE CORRECTION

The original image proposed an exterior forward channel and an interior inverse channel.

Hostile control:

```text
stateless invertible transport T
followed by exact inverse T^-1
=> exact state return
```

Therefore:

> **INVERSE TRANSPORT ALONE DOES NOT CREATE MEMORY.**

A nonzero return residual requires at least one declared source of path dependence:

```text
changed order / noncommutation
explicit state or history
coupling between channels
non-inverse return map
loss / projection / quotient
```

Frozen `delta@1` witness:

```text
exact inverse return:
  endpoint SAME
  internal_state SAME

order-swapped hostile path:
  endpoint SAME
  internal_state DIFFERENT
```

External exact matrix control used during design:

```text
A = [[1,1],[0,1]]
B = [[1,0],[1,1]]
v = [1,2]^T

B A v = [3,5]^T
A^-1 B^-1 (B A v) = v
B^-1 A^-1 (B A v) = [-2,7]^T
```

The important variable is therefore not “inverse interior” by itself, but **the relation between transport order and retained state**.

New correction mathal: `INVERSE-IS-NOT-MEMORY-001`.

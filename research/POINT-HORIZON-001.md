# POINT-HORIZON-001

**Status:** research specimen / candidate mathal  
**Runtime authority:** NONE  
**Operator status:** **NO NEW OPERATOR**

## Purpose

Preserve the bare calculational kernel of THE POINT THING without importing Amber, telescope, symbolic, theological, or narrative authority into Dogram.

The candidate kernel is:

```text
arrived history
-> situated point
-> available action set
-> one explicit action
-> next point
```

with a chronology guard:

```text
later knowledge
!=
earlier availability
```

## State sketch

Let:

```text
P_t = (H_t, A_t)
```

where:

- `H_t` is the attributable information / formation available at the cut;
- `A_t` is the declared set of actions available from that cut.

Optional observer/body/aperture metadata may be carried as opaque fields by the specimen. Dogram does not infer their meaning.

A selected action is:

```text
a* ∈ A_t
```

and one explicit transition produces:

```text
P_t --a*--> P_(t+1)
```

The transition may enlarge or alter both available history and reachable actions.

## Pulse / pull lowering

`PULL` and `PULSE` are research labels, not operators.

Candidate semantics outside runtime authority:

```text
PULL  := current state constrains / ranks available next actions
PULSE := one declared action is actually applied
```

Dogram may only receipt supplied state and transition data.

It must refuse:

```text
why this action was destined
whether the future was already known
whether the action was spiritually or causally 'pulled'
```

unless those claims are independently represented as ordinary evidence-bearing inputs in some upstream system.

## Chronology guard

For a prior point `P_i` inspected from later point `P_j` where `j > i`, carry at least two distinct fields when needed:

```text
available_at_i
known_at_j_about_i
```

Never collapse them into one value.

Candidate seal:

> **LATER KNOWLEDGE MAY DESCRIBE AN EARLIER CUT. IT MAY NOT BECOME THE EARLIER CUT.**


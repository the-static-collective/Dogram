# PARALLEL-EQUIVALENCE-WITNESS-001

Status: bounded research specimen. Authority: none. Public operator: none.

## Question

After `DECLARED-PATH-EQUIVALENCE-001`, does retaining the endpoints and the fact of declared path equivalence determine which rewrite witness licensed the equality?

## Exact specimen

Use three words and three named rewrites:

- `alpha: aa => bb`
- `rho: aa => cc`
- `sigma: cc => bb`

There are then two parallel witnesses from `aa` to `bb`:

- direct witness `alpha` with state trace `aa, bb`;
- composite witness `beta = sigma o rho` with state trace `aa, cc, bb`.

Both induce the same endpoint equality `aa ~ bb`. Their rule traces and state traces are different.

## Delta

`source(alpha) = source(beta) = aa` and `target(alpha) = target(beta) = bb`, while `alpha != beta` as supplied derivations.

**SAME PATH EQUIVALENCE != SAME EQUIVALENCE WITNESS.**

Secondary seal: **EQUALITY CAN BE THE RESULT. THE WITNESS OF EQUALITY IS STILL A THING.**

## Documented mathematics

This is standard rewriting/higher-category territory: rewriting distinguishes terms from rewrite steps and derivations. A presentation generates a quotient/congruence, but the generated equality does not by itself retain a particular derivation witness. Higher-dimensional presentations/computads/polygraphs promote rewrites between 1-cells to 2-dimensional data, with higher cells available to relate parallel derivations.

Scholar Gateway search (2026-09-20) returned literature separating presentations/congruences from quotient structures; Delle Rose, San Mauro & Sorbi (2020), DOI `10.1002/malq.202000021`, explicitly describes an algebra presentation as a term algebra quotiented by the congruence generated by declared relations. Chu & Hackney (2022), DOI `10.1112/jlms.12528`, provides contemporary higher-categorical graphical context where strictification and higher morphism structure are treated explicitly.

Wolfram's `FindStringProof` resource separately returns proof steps/proof graphs for string equivalence, and `MultiwaySystem` exposes branch pairs and their resolutions. Those interfaces independently support the distinction between endpoint equivalence and the proof/branch structure witnessing it.

## Dogram inference

A quotient receipt that stores only `aa ~ bb` cannot reconstruct whether the supplied witness was `alpha` or `sigma o rho`. If witness provenance matters, retain at least the named/hashed derivation path separately from the quotient equality it licenses.

This does **not** yet justify a public 2-cell operator. It earns a research boundary: witness identity is additional receipt data.

# FOATA-PROFILE-COLLISION-001

Status: bounded research slice; no public operator promotion.

## Question

Does retaining only the sizes of the concurrency layers in a Foata/dependence-poset normalization preserve the underlying Mazurkiewicz trace?

No.

## Frozen specimen

Alphabet `Sigma={a,b,c,d}` with the only independent pair `a I b` (symmetrically). Compare `abcd` and `abdc`.

Both words have the same Parikh vector: one occurrence of every symbol.

Adjacent independent swaps give exact trace classes:

```text
[abcd] = {abcd,bacd}
[abdc] = {abdc,badc}
```

The classes are disjoint.

Peeling minimal occurrences from each dependence poset gives full Foata layers:

```text
abcd -> {a,b} | {c} | {d}
abdc -> {a,b} | {d} | {c}
```

The labeled normal forms differ, but their layer-size profiles coincide exactly:

```text
(2,1,1) = (2,1,1)
```

Thus a full labeled Foata normal form can canonically represent a trace relative to the declared independence relation, while the unlabeled concurrency-depth/profile summary is a further lossy quotient.

## Seals

**SAME FOATA LAYER-SIZE PROFILE != SAME TRACE.**

**A CANONICAL REPRESENTATIVE CAN BE LOSSLESS WHILE A SUMMARY OF THAT REPRESENTATIVE IS NOT.**

**KEEP THE LAYER LABELS / DEPENDENCE RECEIPT WHEN TRACE IDENTITY MATTERS.**

## Documented mathematics

Mazurkiewicz trace equivalence is generated by commuting adjacent independent actions. For a fixed independence relation, each trace admits a unique Foata normal form; León, Haar & Longuet use this fact to choose one representative per equivalence class in concurrent-system testing (2014), DOI `10.1002/stvr.1543`.

Partial-order traces and event structures retain labeled order information and admit directed-graph representations; Gao et al. discuss partial-order traces, graph ideals, and event-structure slicing (2014), DOI `10.1155/2014/352152`.

The four-event profile collision above is a bounded Dogram construction; no claim is made that it is published or globally smallest.

## Inference

The exact specimen separates three surfaces under one fixed alphabet and one fixed independence relation:

```text
Parikh counts < layer-size profile < labeled Foata/dependence structure
```

The `<` symbols mean strictly less discriminating for this specimen, not a universal semantic or authority ordering.

## Refusals

```text
FOATA NORMAL FORM != HISTORICAL OCCURRENCE
SAME LAYER PROFILE != SAME TRACE
SAME TRACE != SAME REAL-WORLD HISTORY
DEPENDENCE RELATION != CAUSAL TRUTH
CONCURRENCY LAYER != SIMULTANEOUS OCCURRENCE
CANONICAL REPRESENTATIVE != AUTHORITY
PROFILE COLLISION != EVIDENCE COLLISION
```

## Relation to #113

PR #113 shows that the declared independence relation changes the quotient even when the linear word language is held fixed. This slice holds the independence relation fixed and asks what happens after canonicalization: the full labeled normal form still separates the two trace classes, while retaining only layer cardinalities erases that distinction.

## HOLD

Do not promote `foata@1`, `trace@1`, `dependence_poset@1`, `concurrency_profile@1`, occurrence, evidence, causal, semantic, or authority operators.

Strongest next frontier: compare the full labeled Foata normal form with the labeled dependence poset itself under repeated labels. Determine which representation is reconstructive for a fixed independence alphabet, and isolate exactly where occurrence identity must be retained rather than inferred from labels alone.

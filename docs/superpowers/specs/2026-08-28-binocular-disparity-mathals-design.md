# Binocular Disparity Mathals — Deterministic Companion Design

**Date:** 2026-08-28  
**Status:** ARCHITECTURAL COMPANION DESIGN · NO NEW V0 OPERATOR ADMITTED  
**Repository:** `the-static-collective/Dogram`

## 0. Purpose

This slice gives Dogram the formal/mathematical side of ALEX `BINOCULAR-RECURSION-001` without turning Dogram into a semantic or evidentiary authority.

Dogram’s job remains:

> **DO THE MATH. SHOW THE DELTA. KEEP THE RECEIPT. DO NOT DECIDE WHAT IT MEANS.**

The binocular research pattern can be formalized as two simultaneous views over one constituted state:

```text
compression view
||
expansion view
```

Dogram may calculate the disparity between those views when the inputs are explicit and typed.

Hard boundary:

```text
DOGRAM DISPARITY != EVIDENCE
DOGRAM CLOSURE != TRUTH
DOGRAM COMPRESSION SCORE != EXPLANATORY AUTHORITY
DOGRAM STABILITY != REALITY
```

This document does **not** amend the existing v0 public operator list. It defines a companion specimen family and composition semantics over `delta`, `rectangle`, `ablate`, and `reach` until a future operator earns admission.

## 1. Core mathal

Let the current constituted state be `X_t`.

Let:

```text
C(X_t)
```

be an explicitly supplied compression candidate.

Let:

```text
E_R(X_t)
```

be the deterministic consequence/reachability closure of `X_t` under an explicitly supplied rule or graph relation set `R_t`.

Define the binocular pair:

```text
B(X_t) = (C(X_t), E_R(X_t))
```

Define disparity as a typed comparison rather than assuming a numeric metric:

```text
τ_t = Δ_B(C(X_t), E_R(X_t))
```

`Δ_B` may return equality, first difference, set difference, reachability loss/gain, or another explicitly typed deterministic delta.

It may not invent semantic distance between opaque labels.

---

## 2. The NOW expansion

The expansion side is not prediction by default.

It is closure under the presently declared relation/rule set:

```text
E_R(X_t) = Reach(X_t | R_t)
```

For a directed graph specimen:

```text
G_t = (V_t, E_t)
```

and declared seed set `S_t ⊆ V_t`:

```text
E_R(X_t) = reachable(G_t, S_t)
```

If branch conditions matter, they must be represented as separate explicit specimens or typed graph structure. Dogram does not infer hidden branch semantics.

Thus:

```text
REACHABLE != ENTAILED IN THE WORLD
GRAPH PATH != CAUSAL PATH
```

Dogram reports graph-theoretic closure only.

---

## 3. Compression as candidate generator

Dogram does not decide what the “best explanation” is.

Instead, it can pressure an explicitly supplied candidate generator `C` by asking what is lost when the specimen is reduced to `C` and then re-expanded under the same deterministic relation rules.

Let:

```text
F_t = declared full surface
C_t = declared compressed candidate
R_t = declared deterministic expansion relation
```

Define re-expansion:

```text
RExp_t = E_R(C_t)
```

Then define the two primary set residuals:

```text
L_t = F_t \ RExp_t
S_t = RExp_t \ F_t
```

where:

```text
L_t = compression loss
S_t = surplus generation
```

Interpretation belongs downstream.

Dogram only reports membership differences.

---

## 4. Tension vector

For specimens whose components can be represented as sets or typed comparisons, the binocular tension surface can be represented as a tuple:

```text
τ_t = (
  loss_t,
  surplus_t,
  unresolved_t,
  contradiction_t,
  trajectory_delta_t
)
```

Not every specimen supplies every component.

No scalar “tension score” is admitted in this design because collapsing heterogeneous failure modes into one number would erase structure.

### 4.1 `loss_t`

Declared items present in the full field but absent from re-expansion of the compression candidate.

```text
loss_t = F_t \ E_R(C_t)
```

### 4.2 `surplus_t`

Items generated by the candidate under the declared rule set that are absent from the declared full surface.

```text
surplus_t = E_R(C_t) \ F_t
```

### 4.3 `unresolved_t`

Explicitly declared residual items that no current deterministic relation connects to either side.

Dogram does not discover semantic unresolvedness; it preserves and compares supplied unresolved sets.

### 4.4 `contradiction_t`

A contradiction flag or incompatible pair may be consumed only when the contradiction relation itself is supplied as typed specimen data.

Dogram does not infer logical contradiction from prose.

### 4.5 `trajectory_delta_t`

Difference between outputs produced from equal focus membership under different explicit ordered trajectories.

This preserves:

```text
SAME MEMBERSHIP != SAME PATH
```

## 5. Re-expansion fidelity

A useful deterministic pressure quantity is **re-expansion fidelity**.

For finite set-like specimens:

```text
F_t     = full declared reachable/output set
RExp_t  = re-expanded output from compressed candidate
```

Dogram may emit exact structural counts:

```text
missing_count = |F_t \ RExp_t|
surplus_count = |RExp_t \ F_t|
match          = (F_t == RExp_t)
```

Optionally, when both sets are explicitly finite and set semantics are declared, a Jaccard comparison may be computed in a future admitted operator/profile:

```text
J(F_t, RExp_t) = |F_t ∩ RExp_t| / |F_t ∪ RExp_t|
```

but this design does not require adding it to v0.

A perfect set match means only structural equality under the supplied specimen and rule set.

```text
PERFECT RE-EXPANSION != TRUE MODEL
```

## 6. Compression pressure by ablation

Existing/planned `ablate` semantics can pressure a candidate generator.

Given generator components:

```text
C = {c1, c2, ..., cn}
```

for each component `ci`, remove it and recompute declared reachability consequences.

Conceptually:

```text
impact(ci) = Reach(C, R) \ Reach(C \ {ci}, R)
```

Dogram may report:

- reachability pairs lost;
- requested targets no longer reachable;
- graph digest before/after;
- no-change ablations.

A component with zero measured impact under one specimen is not globally irrelevant.

```text
NO LOCAL DELTA != UNIVERSAL REDUNDANCY
```

---

## 7. Expansion closure pressure

Existing/planned `reach` semantics can model the “follow NOW to each logical conclusion” side when the relation system is an explicit directed graph.

For declared start nodes `S` and graph `G`:

```text
closure(S, G) = {v | ∃ path from some s ∈ S to v}
```

The result may include shortest unweighted graph paths as calculational witnesses.

It must preserve:

```text
PATH FOUND != HISTORICAL ANCESTRY
REACHABLE != REQUIRED
REACHABLE != TRUE
```

---

## 8. Disparity via `delta`

The existing/planned `delta` operator already supplies the simplest useful binocular primitive:

```text
left_trace  = compression/re-expansion boundary trace
right_trace = full/expansion boundary trace
```

Dogram can report the first declared boundary at which the two differ.

Example boundary order:

```text
FIELD
GENERATOR
REEXPANSION
RESIDUAL
```

Possible result:

```text
FIELD       SAME
GENERATOR   DIFFERENT
REEXPANSION DIFFERENT
RESIDUAL    DIFFERENT

first_difference = GENERATOR
```

Dogram reports location of divergence, not whether that divergence is epistemically acceptable.

## 9. Interaction via `rectangle`

`rectangle` can test whether compression and expansion pressures interact rather than simply add.

A synthetic two-axis specimen may use:

```text
axis A = compression profile 0/1
axis B = expansion profile 0/1
```

with four declared numeric outcomes:

```text
F00 F01
F10 F11
```

Numeric interaction:

```text
mixed_delta = F11 - F10 - F01 + F00
```

For opaque outcomes, Dogram reports equivalence-pattern change only.

Interpretations such as “binocular depth emerges only when both lenses are active” remain ALEX/human conclusions, not Dogram output.

## 10. Trajectory dependence

A major purpose of this slice is to make ordered traversal pressure explicit.

Let a traversal be:

```text
T = [v0, v1, ..., vk]
```

with repeated nodes permitted.

Two trajectories may have equal membership:

```text
set(T1) = set(T2)
```

while differing in order:

```text
T1 != T2
```

A deterministic downstream transformation `P` may then produce:

```text
P(T1) != P(T2)
```

The appropriate Dogram result is not “one path is better.” It is:

```text
trajectory_dependence_detected: true
```

provided the specimen declares the same initial state and transformation profile and only the trajectory differs.

No new v0 operator is required immediately; this can first be represented as paired deterministic traces compared with `delta`.

## 11. Recursive pass mathal

A binocular run may be represented as a sequence:

```text
B_0, B_1, ..., B_n
```

where each pass has:

```text
B_t = (C_t, E_t, τ_t)
```

and each next state is externally supplied with an attributable update receipt:

```text
X_(t+1) = U_t(X_t)
```

Dogram does not invent `U_t`.

It may compare pass receipts.

### 11.1 Fixed

For canonical deterministic payloads:

```text
digest(B_t) == digest(B_(t+1))
```

under unchanged declared profiles.

This is a calculational fixed point only.

### 11.2 Cycle

There exist `i < j` such that:

```text
digest(B_i) == digest(B_j)
```

and the repeated segment contains at least one distinct intervening state.

### 11.3 Residual

A stable shared component remains while a declared residual set stays non-empty across the bounded pass window.

### 11.4 Divergent

No repeated canonical binocular state appears within the declared bounded pass limit and new structural deltas continue to appear.

Dogram may detect the pattern. ALEX decides whether the research formation is valid and what stopping label is appropriate under its protocol.

## 12. Companion specimen envelope

Until a dedicated operator is admitted, binocular mathals can be stored as ordinary Dogram specimens with explicit metadata/profile fields that remain non-operative except where consumed by an existing operator.

Conceptual companion record:

```json
{
  "schema": "dogram.binocular-specimen/v0",
  "specimen_id": "binocular-001",
  "field_digest": "sha256:...",
  "compression": {
    "generator_nodes": ["A", "B"]
  },
  "expansion": {
    "seed_nodes": ["A"],
    "graph": {
      "nodes": ["A", "B", "C"],
      "edges": [["A", "B"], ["B", "C"]]
    }
  },
  "trajectory": ["A", "B", "A", "C"],
  "declared_full_surface": ["A", "B", "C"]
}
```

A wrapper or fixture compiler may translate this companion specimen into one or more ordinary `delta`, `reach`, `ablate`, or `rectangle` specimens.

The compiler itself must be deterministic and receipt-bearing before it may become executable infrastructure.

## 13. Canonical composition recipes

### 13.1 Compression-loss recipe

```text
1. reach(full seed, full graph)
2. reach(compressed seed/generator, same graph)
3. delta(full closure, compressed re-expansion)
4. report missing/surplus structural items
```

### 13.2 Generator-ablation recipe

```text
1. compute baseline reachability
2. ablate exactly one generator component
3. recompute reachability
4. report lost/gained reachability
```

### 13.3 Trajectory recipe

```text
1. supply same initial state
2. supply T1
3. supply T2
4. run same declared deterministic transformation
5. delta outputs
```

### 13.4 Binocular-interaction recipe

```text
1. construct four declared outcomes
2. compression off/on × expansion off/on
3. rectangle
4. report interaction only
```

## 14. First hostile mathal specimens

The first durable fixture family should contain synthetic, domain-neutral cases.

### `perfect-reexpansion`

Compression candidate re-expands exactly to the declared full surface.

Expected mathal:

```text
loss = ∅
surplus = ∅
match = true
```

No truth promotion.

### `compression-drops-live-branch`

Re-expansion misses one declared reachable branch.

Expected mathal:

```text
loss != ∅
```

ALEX may later classify the omission constitutionally.

### `compression-overgenerates`

Candidate produces an extra reachable item absent from the declared full surface.

Expected mathal:

```text
surplus != ∅
```

### `same-membership-different-trajectory`

Two trajectories visit the same node set in different order and produce different supplied deterministic outputs.

Expected mathal:

```text
trajectory_dependence_detected = true
```

### `fixed-point-not-truth`

Two consecutive binocular payloads are canonically equal.

Expected mathal:

```text
fixed = true
```

Receipt wording must not contain semantic promotion such as `true_model` or `proved`.

## 15. Future operator admission test

A dedicated operator such as `binocular` or `disparity` should be admitted only if composition through existing v0 operators becomes materially awkward or lossy.

Admission requires evidence that a dedicated operator provides at least one of:

1. a deterministic result that cannot be expressed cleanly through `delta`, `reach`, `ablate`, and `rectangle`;
2. a materially safer canonical receipt boundary;
3. substantial fixture simplification without importing ALEX semantics.

Until then, YAGNI applies.

---

## 16. Acceptance criteria for this design

This companion design is sound only if:

1. no formula requires Dogram to infer meaning from prose;
2. no result promotes reachability, compactness, stability, or disparity into truth/support/evidence;
3. heterogeneous tension classes remain typed rather than collapsed into one score;
4. exact set/graph differences are preferred to invented distances;
5. ordered trajectory is preserved when order is part of the specimen;
6. recursive state changes remain externally attributable rather than invented by Dogram;
7. existing v0 operator boundaries remain intact;
8. the ALEX/Dogram ownership line remains explicit.

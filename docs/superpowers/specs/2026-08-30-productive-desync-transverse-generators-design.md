## 2. Exact finite model

Let

\[
G=\mathbb Z_m\times\mathbb Z_n
\]

and let ordinary coherent motion be generated by

\[
\sigma=(1,1).
\]

The synchronized subgroup is

\[
H=\langle(1,1)\rangle.
\]

Its order is

\[
|H|=\operatorname{lcm}(m,n).
\]

Since `|G|=mn`, the number of synchronized phase sheets is

\[
[G:H]
=\frac{mn}{\operatorname{lcm}(m,n)}
=\gcd(m,n).
\]

Define

\[
d=\gcd(m,n).
\]

A sheet coordinate is

\[
\phi(a,b)=(a-b)\bmod d.
\]

Synchronous motion preserves it:

\[
\phi(a+1,b+1)=\phi(a,b).
\]

Hence

\[
G/H\cong\mathbb Z_d.
\]

The states on other sheets are not absent from the declared state capacity; they are inaccessible under the baseline generator.

```text
CAPACITY != ACCESSIBILITY
```

### 2.1 No-hidden-sheet boundary

If

\[
\gcd(m,n)=1,
\]

then

\[
|H|=mn
\]

and synchronized motion already covers the entire state space.

There is no nontrivial quotient sheet to cross.

Under this fixed state model, no asymmetric move can produce a strict reachability increase beyond `mn`.

Hard control:

```text
NO HIDDEN QUOTIENT != NO LOCAL DIFFERENCE
```

The model may still admit changed traces or states, but not a quotient reachability lift.

## 3. Typed asymmetric cut

Permit a bounded one-coordinate move

\[
\alpha_r=(r,0).
\]

It changes sheet coordinate by

\[
\phi(a+r,b)=\phi(a,b)+r\pmod d.
\]

The cut is transverse exactly when

\[
r\not\equiv0\pmod d.
\]

If `r ≡ 0 mod d`, local state may change while the quotient sheet remains unchanged.

Therefore:

```text
ASYMMETRY != PRODUCTIVE ASYMMETRY
```

## 4. One-shot crossing != generator closure

The original `Z6 x Z4` specimen has `d=2`, so a single transverse cut happens to expose the only other sheet.

That is not the general rule.

A single transverse cut enters one other coset. Ordinary synchronized motion can then resume coherently inside that new sheet.

```text
current sheet
  -> one typed transverse cut
  -> one new sheet
  -> coherent motion resumes
```

For

\[
G=\mathbb Z_6\times\mathbb Z_9,
\qquad d=3,
\]

the synchronized orbit has `18` states.

One `r=1` cut plus synchronization gives a union of `36` states, not all `54`.

If the same typed cut is permitted again in a later bounded cycle, the third sheet becomes reachable.

Keep two witnesses separate:

```text
ONE-SHOT-CROSSING
TRANSVERSE-GENERATOR-CLOSURE
```

## 5. Transverse lift index

If `alpha_r` is available across repeated bounded cycles, the quotient subgroup it generates has order

\[
\Lambda(r)=\frac{d}{\gcd(d,r)}.
\]

This is the number of quotient sheets reachable under the closure generated by synchronized motion plus the typed asymmetric move.

Reachable state count:

\[
|\mathcal R_r|
=
\operatorname{lcm}(m,n)
\cdot
\frac{d}{\gcd(d,r)}.
\]

### Inert asymmetry

\[
\gcd(d,r)=d
\Rightarrow
\Lambda(r)=1.
\]

### Partial transverse lift

\[
1<\gcd(d,r)<d
\Rightarrow
1<\Lambda(r)<d.
\]

### Full transverse lift

\[
\gcd(d,r)=1
\Rightarrow
\Lambda(r)=d.
\]

The index measures quotient reachability expansion only.

```text
PRODUCTIVITY HAS AN INDEX.
INDEX != VALUE.
```

## 6. Complementary asymmetric generators

For a declared family

\[
R=\{r_1,\ldots,r_k\},
\]

the generated quotient reach is

\[
\Lambda(R)
=
\frac{d}{\gcd(d,r_1,\ldots,r_k)}.
\]

### Exact specimen

Let

\[
G=\mathbb Z_{12}\times\mathbb Z_{18},
\qquad d=6.
\]

Synchronized sheet size:

\[
\operatorname{lcm}(12,18)=36.
\]

For `r=2` alone:

\[
\Lambda(2)=3
\]

so reachable states = `108`.

For `r=3` alone:

\[
\Lambda(3)=2
\]

so reachable states = `72`.

Together:

\[
\gcd(6,2,3)=1
\Rightarrow
\Lambda(2,3)=6,
\]

so all `216` states are in the generated closure.

Neither declared difference spans the quotient alone. Together they do.

```text
COMPLEMENTARY DIFFERENCE CAN GENERATE REACHABILITY
THAT NO DECLARED DIFFERENCE GENERATES ALONE.
```

This does not prove a federation-only capability. A centralized system with lawful access to both generators may reproduce the same closure. Stronger federation claims require locality or non-transferability constraints.

## 15. Proof sketch

The synchronized generator `(1,1)` has order equal to the smallest positive `k` satisfying

\[
k\equiv0\pmod m,
\qquad
k\equiv0\pmod n,
\]

which is `lcm(m,n)`.

Thus

\[
|H|=\operatorname{lcm}(m,n).
\]

By finite-group index arithmetic,

\[
[G:H]
=\frac{mn}{\operatorname{lcm}(m,n)}
=\gcd(m,n)=d.
\]

The homomorphism

\[
\phi:\mathbb Z_m\times\mathbb Z_n\to\mathbb Z_d,
\qquad
\phi(a,b)=a-b\pmod d
\]

has kernel `H`, so

\[
G/H\cong\mathbb Z_d.
\]

The asymmetric move `(r,0)` maps to `r mod d` in the quotient. The cyclic subgroup generated by that residue has order

\[
d/\gcd(d,r).
\]

For multiple residues, the generated subgroup of `Z_d` has order

\[
d/\gcd(d,r_1,\ldots,r_k).
\]

This is the transverse lift index.

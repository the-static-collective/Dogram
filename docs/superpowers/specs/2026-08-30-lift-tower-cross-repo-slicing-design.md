# Lift Tower Cross-Repo Slicing Design

**Date:** 2026-08-30
**Status:** design checkpoint before implementation
**Scope:** bounded durable capture across Dogram, 3rdi, ALEX.2, and national-treasure

## Purpose

Preserve the durable mathematical, observer-local, epistemic, and formation-trace results from the recent phaselift / timing / extrusion / stewardship conversation without duplicating existing PHASELIFT material or silently expanding runtime authority.

The design intentionally separates ownership by repo rather than copying one giant narrative everywhere.

## Existing boundaries

- Dogram calculates declared relations and residuals. Existing `LIFT-GATE-001` remains outside runtime promotion.
- 3rdi owns observer-local projection semantics and currently uses `occurrence`, `availability`, `focus`, and `known-at` as its established coordinates.
- ALEX owns research-pressure, evidence, formation ancestry, and promotion questions.
- national-treasure owns the conversation formation trace and symbolic/theological/analogical strata.
- Existing PHASELIFT material remains historically intact; this design adds only genuinely new descendants.

Candidate non-collapse:

```text
t_occurrence
!= t_availability
!= t_observation
!= t_known
!= s_local
```

Here `s_local` is a typed process-local progression / age coordinate attached only when a declared process needs it.

Required controls:

- `s_local` is not automatically availability time or known-at time;

Candidate law:

> **THE SMALLEST LIFT THAT RESTORES LAWFULNESS WINS.**

A proposed lift must be declared before held-out evaluation and must materially improve at least one target-relative criterion such as:

- held-out prediction;
- compression with preserved target sufficiency;
- state sufficiency / reduction of apparent history dependence;
- discrimination between frozen candidate generators;
- lawful replay or reconstruction.

Required non-collapses:

```text
LIFTED != RESOLVED
MORE DIMENSIONS != BETTER EXPLANATION
COHERENCE != REIFICATION
POST-HOC FIT != PREDICTION
```

Kill or demote the lift if the additional coordinate adds notation without a stable discriminator.

## Non-goals

This slice does not:

- declare literal hidden spatial dimensions;
- identify symbolic resonance with historical intent;
- promote a new Dogram runtime operator;
- add a permanent fifth 3rdi coordinate;
- treat family/system models as moral exoneration or blame assignment;
- collapse stewardship into sovereignty;
- rewrite existing PHASELIFT or testimony receipts.

## Verification plan

For every repo slice:

1. branch from fresh current default-branch head;
2. keep the change bounded to the declared owner surface;
3. run or inspect repository-native checks where applicable;
4. verify changed-file list and diff against the design;
5. verify no unintended runtime/schema/authority promotion;
6. open a draft PR unless repository convention strongly indicates otherwise;
7. report exact branch / commit / PR receipts.

## Implementation order

1. Dogram research packet and any frozen fixtures/tests that only use existing operators.
2. 3rdi observer-local process-time specimen.
3. ALEX promotion-gate specimen.
4. national-treasure formation trace.

Each slice is independently reviewable and must not depend on another slice having already merged.

## MutatedMathal lowering recipe

```text
MUTATED MATHAL
    -> choose one discriminator
    -> choose the smallest Dogram operator
    -> declare typed specimen
    -> run calculation
    -> retain calculation receipt
    -> send receipt to ALEX / human pressure
```

A single mathal may lower into several specimens. `OK` means only that Dogram executed the declared operator successfully. If a new mathal cannot be expressed with the current operators, preserve that failure; it may justify a future operator rather than hidden special-casing.

## v0 operator floor

- `delta@1` — compare ordered typed boundary traces and name the first difference.
- `rectangle@1` — test 2×2 numeric mixed differences or opaque equivalence interactions.
- `ablate@1` — remove one graph node/edge and report lost reachability.
- `reach@1` — apply one explicit graph mutation and report before/after reachability.

Opaque values are compared only for equality. Integer/rational arithmetic stays exact. Metadata is receipted in the specimen digest but is non-operative in v0.
